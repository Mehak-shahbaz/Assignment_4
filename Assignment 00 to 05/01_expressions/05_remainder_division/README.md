➗ Remainder & Quotient Calculator
🔢 Formula Used
This program calculates both the quotient and remainder from a division operation:
[ \text{Quotient} = \frac{\text{Dividend}}{\text{Divisor}} \quad (\text{integer division}) ] [ \text{Remainder} = \text{Dividend} \mod \text{Divisor} ]

💡 Features
✔️ Accepts user input for dividend and divisor
✔️ Uses integer division (//) for the quotient
✔️ Uses modulus (%) to find the remainder
✔️ Displays output in a readable format

📝 Code Breakdown
Takes input for the dividend and divisor
Performs integer division (//) to compute the quotient
Uses modulus (%) to find the remainder
Displays the result in a formatted message

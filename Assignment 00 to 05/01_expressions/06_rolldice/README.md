🎲 Dice Rolling Simulator 🎲
📝 How It Works
This Python script simulates rolling two dice and calculates their total.

🔢 Steps in the Code
Imports the random module for generating random numbers
Defines NUM_SIDES = 6, as standard dice have six sides
Generates two random numbers (between 1 and 6) for each die
Calculates their total
Displays the results
🚀 How to Run the Program
Navigate to the project folder:
cd Project-4-Assignments/Assignments\ 00\ to\ 05/01_expressions/06_rolldice/
Run the script:
python main.py
Sample Output:
Each die has 6 sides.
First die: 4
Second die: 2
Total of two dice: 6
